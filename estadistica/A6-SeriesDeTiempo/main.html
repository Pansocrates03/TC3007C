Identifica si es una serie estacionaria

La prueba de fuller cuenta con las siguienes hipótesis \(H_0=\) La serie no es estacionaria \(H_1=\) La serie es estacionaria

library(tseries)
## Registered S3 method overwritten by 'quantmod':
##   method            from
##   as.zoo.data.frame zoo
library(ggplot2)

adf_test_result <- adf.test(serie_de_tiempo_ventas)

print(adf_test_result)
## 
##  Augmented Dickey-Fuller Test
## 
## data:  serie_de_tiempo_ventas
## Dickey-Fuller = -2.7111, Lag order = 2, p-value = 0.3015
## alternative hypothesis: stationary

\(H_0\) = La serie NO es estacionaria. \(p\)-value (\(0.3\)) > \(\alpha\) (\(0.05\)). Cuando \(p\) es alto, NO se rechaza \(H_0\). Conclusión: No rechazamos la hipótesis de que la serie no es estacionaria. Por lo tanto, concluimos que la serie NO es estacionaria.

Realiza la regresión lineal de la tendencia (ventas desestacionalizadas vs tiempo)

# --- ANÁLISIS DEL MODELO LINEAL DE LA TENDENCIA ---

# 1. Calcular la serie desestacionalizada (Original / Estacional)
#    Y = T * S * R  =>  Deseasonalized (T*R) = Y / S
#    Esto tendrá NAs al inicio y al final, heredados de la tendencia.
serie_desest_mult <- serie_de_tiempo_ventas / modelo_multiplicativo$seasonal

# 2. Graficar la serie desestacionalizada
plot(serie_desest_mult, 
     main="Serie Desestacionalizada (Original / Estacional)",
     ylab="Ventas Desestacionalizadas (T*R)",
     col="blue")

# 3. Preparar datos para la regresión (Manejo de NAs)
tiempo <- 1:length(serie_desest_mult) # Vector de tiempo (1 a 16)
 
# 4. Alineación de datos (ELIMINA EL ERROR)
#    Encontramos los índices donde la serie desestacionalizada NO es NA
indices_validos <- which(!is.na(serie_desest_mult))
 
#    Creamos vectores alineados (longitud 12, en este caso)
tiempo_alineado <- tiempo[indices_validos]
ventas_desest_alineadas <- serie_desest_mult[indices_validos]
 
# 5. Crear el dataframe para la regresión
datos_regresion <- data.frame(
     Tiempo = tiempo_alineado,
     Ventas_Desest = ventas_desest_alineadas
)
 
# 6. Ajustar el modelo de tendencia lineal
modelo_tendencia_lineal <- lm(Ventas_Desest ~ Tiempo, data = datos_regresion)
 
summary(modelo_tendencia_lineal)

Para hacerlo usaremos la prueba de Ljung-Box. El cuál tiene: \[H_0: \text{Los residuos son independientes}\] Para tenerlo se necesita un p-value > 0.05

residuos_tendencia <- residuals(modelo_tendencia_lineal)
